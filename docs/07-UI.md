# 07 · UI — 风格预设、尺子、记忆点、主屏规格

闸 A 的第二件交付物。写于 2026-11-14，早于第一版界面。

## 1. 风格预设：`kiln-ember`

一间景德镇柴窑的夜班。深炭底、砖红、釉色瓷器、一束暖光。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--ink` | `#0B0908` | 页底、窑外 |
| `--ink-2` | `#14100E` | 卡片底 |
| `--brick` | `#2A1D17` | 窑体 |
| `--ember` | `#E2531F` | 唯一强调色：主按钮、选中、印章 |
| `--ember-hot` | `#FFB35E` | 火、命中、正偏差 |
| `--porcelain` | `#F2EDE4` | 正文 |
| `--muted` | `#A3958A` | 说明、次级 |
| `--celadon` `--cobalt` `--gold` | `#8FB3A4` `#7E9BD1` `#D8B25A` | 三种釉色 + 窑变 |
| `--bad` | `#C9563C` | 生烧／过火、错误 |

字：`Fraunces Variable`（展示、数字，带 SOFT/WONK 轴，像手写价签）＋ `Inter Variable`（正文、按钮）。
字阶只六级：11（kicker）／12（说明）／13（次级）／15（正文）／20（小标题）／27–40（印章与主标题）。
行高：正文 1.5，展示 1.05。数字一律 `tabular-nums`。

版式规矩：
- 一屏一物：窑是唯一主角，任何 UI 都不许比窑亮。
- 一个强调色，只给「现在能点的」和「这把成了」。
- 卡片圆角 14，窑室圆角 12，按钮全圆角；描边一律 `rgba(242,237,228,0.14)`。
- 不用阴影糊；阴影只给「物件离地」的地方（窑体、印章）。

## 2. 尺子（每一件只学一点）

| 参考 | 是什么 | 学哪一点 |
| --- | --- | --- |
| **Hexaword**（u/another_moose，Fun & Games with Devvit Web Hackathon 的 **Best Daily Game App**，https://devpost.com/software/hexaword） | 深青底的六边形拼字，一盘一日 | 顶栏只有三样：名字、倒计时、目标预览；没有菜单、没有教程按钮。**一屏就是全部。** |
| **Cattack!**（u/derppherppp，Games with a Hook 2026 的 **Best Use of Phaser** $5,000，https://www.phaser.io/news/2026/08/games-with-a-hook-hackathon-phaser-winners） | 手绘猫卡牌 + 星球地图 | 手画的资产本身就是身份。**「每天一包新卡」这种一句话钩子，比十个功能有用。** |
| **Myndrot**（u/SaintFlow + u/External-Morning-973，同赛 Honorable Mention） | 像素世界，敌人被打败就加入你，草叶会随动物弯腰 | 气氛是工艺信号：会动的草不必被看见，但少了它整屏就廉价。**给环境加一层会呼吸的东西。** |
| **Honk**（u/thejohnnyr，30 万订阅，Reddit 官方博客 https://developers.reddit.com/docs/blog） | 一只鹅、一条路径、玩家自己造关 | 两秒读懂。**一个动词（点、放、走）撑起整个游戏。** |
| **Chook**（同作者，早期黑客松第一名，同博客） | 低多边形 3D，大家合力喂一只鸡 | 合作框架不需要多人实时：**共同目标 + 看得见的共同进度**就够了。 |
| 官方点名的四个每日游戏：r/hotandcold、r/ColorPuzzleGame、r/syllo、r/pocketgrids（https://redditgameofday2026.devpost.com/） | 同平台、同一批评委 | 日更的形态是「同一天所有人同一题 + 连续天数」。**streak 是回访的主发动机。** |

从上面七件读出来的六条，当检查表用：

1. 一屏一物；任何 UI 不许比主角亮。
2. 顶栏三样以内；倒计时一定要有，它制造「今天还没做」的紧迫。
3. 手画的一层（砖、火、釉）比任何图标库都值钱。
4. 环境要会呼吸：火要动、烟要动、釉要有反光。
5. 一个动词：放 → 投柴 → 开。三下结束。
6. 结束要有「结果卡 + 明天见」：名次／分数／连续天数／一句邀请。

## 3. 一个记忆点

> **一座所有人都往里放东西的砖窑：你的器是窑里一枚亮着的剪影，旁边是别人的。**

这条要同时满足三个条件才算成立：窑是**同一个**（同一张图、同一组窑位）、别人**看得见**（窑厂列出用户名的器）、你**只有一个位置**（一人一件，不能改）。
所以主屏不画抽象格子，画一间真的横截面砖窑；不画图标，画九件器的剪影。

## 4. 主屏规格

画布 `1000 × 560`（逻辑坐标），等比 letterbox 进容器；`devicePixelRatio` 上限 2。

| 元素 | 规格 |
| --- | --- |
| 窑体 | `x 70→930, y 150→470`，圆角 12，砖纹 15px 一行、52px 一缝，种子里出纹理 |
| 三室 | 火口 `x 92 w 258`／窑身 `x 384 w 250`／窑尾 `x 668 w 246`，室间墙 28px |
| 架 | 三条：`y = 252 / 352 / 452`，每架高 96 |
| 窑位点击区 | 室宽 −16 × 96；空格画虚线椭圆（半径 22×5） |
| 器物 | 高 60–84，宽 16–68，四种剪影（碗／罐／瓶／蛋瓶），釉色由器物定、再按用户名做 ±9% 色相偏移 |
| 火 | 火口是拱形开口，口内自下而上的暖色渐变；每室 1–3 条舌状火苗，透明度 0.08–0.22 |
| 烟 | 22 个粒子，从烟囱口升起，半径 4→40，透明度 ≤0.08 |
| 前景 | `y 486→560` 渐隐暗带 + 14 块碎砖，把窑「放回地上」 |

顶栏（DOM，非画布）：`KILN` 字标 + 日期与天气一句 + `closes in 15h 00m` + 静音键。
底栏（DOM）：随阶段换；永远最多两行文字 + 一个主按钮 + 一个次按钮。
移动端 390px：三件器竖排成一行一行，主按钮仍在拇指区。

验：`node scripts/shot.mjs` 出 1280×820 与 390×844 两种截图；`scripts/measure-ui.mjs` 断言主按钮 ≥ 44px 高、正文 ≥ 13px、无横向溢出。

## 单测在测什么（34 条）

| 组 | 断言 | 为什么值得测 |
| --- | --- | --- |
| 每日窑 | 同一天所有人拿到同一座窑；换一天必变；9 窑位 3 器；温度落在 1170–1345 | 每日游戏的根：种子必须确定 |
| **可解性** | **365 天 × 每件器 × 空窑／同室已有 3 件，都存在能落在精品带的窑位与投柴** | 防「今天这窑根本不可能做好」——这是每日游戏最容易出的致命 bug |
| 提示诚实 | 界面说「能精品」当且仅当真能（120 天全组合） | 提示不能撒谎，否则玩家学不到真规则 |
| 投柴 | 死手 −18°C、满手 +36°C、中位 +9°C；NaN/负数/超界都被 clamp | 客户端可以乱传，服务端要能扛 |
| 判定 | ±7 精品、±20 合格、之外生烧/过火；窑变只在窑身且 6% | 边界值逐个钉住 |
| 提交 | 一人一天一件；重复提交返回同一件；同室每多一件降 7°C；未知器/位被拒 | 计分与公平 |
| 连续 | 同日不变、次日 +1、断签归 1；跨月跨年 | 回访的核心 |
| 窑厂 | 按提交顺序列出；当日榜从高到低 | 社区感的载体 |
| 脏数据 | Redis 里塞 `not-a-number` 不崩，按 0 处理 | 线上一定会遇到 |

## 已知的软处

1. **第一眼仍不是「海报级」**：`01-card.png` 有主体、有字、对比够，但构图偏平（大块砖红 + 一枚蓝罐），放 300px 能认出「窑 + 瓷」，还谈不上让人停手。下一轮第一件事是重做这一张。
2. 器物只有四种剪影，同一天里会出现两三件长得很像的。
3. 窑厂只列名字与温度，没有头像/名次；社区感靠「同一座窑」这件事撑，不靠社交功能。
